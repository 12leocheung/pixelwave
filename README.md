## 📖 What Is This?

PixelWave Arcade is a solo-developed, hand-built retro games hub containing **28 original browser games** and **15 interactive tools & labs**, all living as individual HTML files in a single repository. No build step, no npm, no bundler — open the file, play the game.

It's been in continuous development since 2017, with games ranging from multiplayer poker tables to full first-person 3D museums to a pitch-black FPS where you shoot by sound alone.

## 🏗 How It's Built

```
pixelwave/
├── index.html                   ← The hub — tabs, cards, donation banner
├── conways-dungeon/             ← Unity WebGL build (the Steam demo)
├── <game-name>.html             ← Every arcade game is a single file
└── <tool-name>.html             ← Every tool is a single file
```

### Philosophy

Every file on this site is **self-contained**. No CDN fonts are required at runtime (they're loaded from Google Fonts as a progressive enhancement). No frameworks. No build step. Drop any `.html` file into a browser and it works.

### Tech Stack

| Layer | Tech |
|-------|------|
| **Structure** | HTML5 (semantic, single-file) |
| **Style** | Vanilla CSS3 — custom properties, grid, animations |
| **Logic** | Vanilla JavaScript — no libraries, no bundlers |
| **3D / Physics** | Custom WebGL / Canvas 2D (built from scratch) |
| **Multiplayer** | Peer-to-peer via WebRTC (no server required) |
| **Hub** | Single `index.html` with tab routing and a Ko-fi donation tracker |
| **Hosting** | GitHub Pages (zero-config, zero cost) |

### Design System

The arcade runs on a consistent retro synthwave design system defined in `:root` CSS variables:

```css
--pink:   #ff2bd6   /* neon magenta  — primary CTA, glows */
--cyan:   #00fff2   /* neon cyan     — secondary CTA, borders */
--purple: #a742ff   /* deep violet   — cards, accents */
--yellow: #ffe14d   /* warm amber    — labels, progress bars */
--bg:     #0a0014   /* near-black    — base background */
--card:   #170a2c   /* dark purple   — card fill */
```

Typography: **Press Start 2P** (pixel headers) + **VT323** (body text) via Google Fonts.

## 🚀 Running Locally

No install required. Just clone and open:

```bash
git clone https://github.com/12leocheung/pixelwave.git
cd pixelwave
# Open index.html in any browser — done.
```

Or for the Conway's Dungeon WebGL build (which needs a local server due to Unity's file loading):

```bash
# Python 3
python -m http.server 8080
# Then visit http://localhost:8080/conways-dungeon/
```
